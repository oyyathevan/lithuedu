🧪 Activity 3.2Unit III

SCAMPER Exercise

⏱ 40 min👥 IndividualProduct: Existing bus timetable / arrival board

👨‍🏫 What the Student Should Do

  1. Choose one product/process (here: static bus board / printed timetable).
  2. Apply each SCAMPER letter to one element at a time.
  3. Write a concrete idea for S, C, A, M, P, E, R — no vague “make it better”.
  4. Note which lens was most productive and which was hardest.
📐 SCAMPER on: Static bus arrival board
S
Substitute paper times with live LED digits
C
Combine board + student phone push alerts
A
Adapt airport flight-board style to buses
M
Modify size — pocket card version of the board
P
Put to use as campus event display after hours
E
Eliminate fixed times; show only “arriving in X min”
R
Reverse — bus “calls” the stop when near, not user checking board

🔁 SCAMPER Output — Model Answer

S · SubstituteReplace printed schedule with live digital countdown from GPS.
C · CombineBoard + college ID card: tap card to see only your usual routes.
A · AdaptBorrow airport “Departures” board layout for multi-route stops.
M · ModifyLarger high-contrast numbers for elderly / low light.
P · Put to other useSame screen shows class delay notices in the evening.
E · EliminateRemove full day timetable; show only next 3 buses.
R · ReverseInstead of user checking board, bus sends “I’m 2 min away” to subscribed phones.

🧠 Reflection

1. Most productive: Reverse — flipped the interaction and opened the “bus calls you” direction.

2. Hardest: Put to another use — the board feels single-purpose; stretching it took more thought.

🧪 Activity 3.3Unit III

Brainwriting Exercise

⏱ 30 min👥 Group (4–6)

👨‍🏫 What the Student Should Do

  1. Each person writes 3 ideas silently (2–3 min).
  2. Pass the sheet; read previous ideas; add 3 new ones that build on them.
  3. Repeat until sheets return; no talking during writing.
  4. Discuss best ideas as a group and list them.

💡 My Ideas (before passing) — Model

  1. App that shows only my two daily buses with live ETA.
  2. Stop light that turns green when any bus is < 3 min away.
  3. Shared class chat auto-posts “Bus 12 spotted at Main Gate.”

🌟 Best Ideas from the Group — Model

  1. Hybrid: live ETA app + physical green light at the stop (built on #1 + #2).
  2. “Bus spotted” button that updates everyone’s map (built on #3).
  3. Morning “leave by 7:42” alarm that adjusts with live delay.

🧠 Reflection

1. Silent vs talking: Silent writing gave quieter members equal voice and reduced dominant opinions.

2. Building on ideas: Seeing someone improve my “app” idea into a hybrid felt rewarding and less competitive.

🧪 Activity 3.4Unit III

Biomimicry-Based Ideation

⏱ 45 min👥 IndividualProblem: reliable arrival info before leaving

👨‍🏫 What the Student Should Do

  1. Pick the problem (need for trustworthy arrival signal).
  2. Find 3 organisms with a relevant strategy (not just “looks cool”).
  3. For each: Organism → Strategy → My product idea.
  4. Translate strategy into a concrete human solution.

🐦 Nature → Solution — Model Answer

1 Organism: Honeybee waggle dance
Strategy: Precise direction + distance signal to the hive
My idea: Phone vibration pattern that encodes “route + minutes left” so students can feel arrival info without looking.
2 Organism: Firefly synchronised flashing
Strategy: Group light signal that is easy to notice at a distance
My idea: Stop lamp that pulses faster as the bus approaches — readable from the hostel gate.
3 Organism: Ant pheromone trails
Strategy: Path strength increases with successful use
My idea: Crowdsourced reliability score: routes that arrived on time get stronger “trust trail” in the app ranking.

🧠 Reflection

1. Surprising strategy: Firefly sync — using pulse rate as a distance cue is simple and low-tech.

2. Why nature helps: Nature has already solved signal, timing, and coordination problems under real constraints.

🧪 Activity 3.5Unit III

AI-Assisted Idea Generation & Critical Evaluation

⏱ 40 min👥 IndividualAI tool: ChatGPT / similar

👨‍🏫 What the Student Should Do

  1. Write a clear prompt with your HMW and user context.
  2. Ask AI for 8–10 ideas.
  3. Evaluate top 5 with Desirable / Feasible / Viable checkboxes.
  4. Reject ideas that ignore real constraints (data access, cost, literacy).

🤖 AI Prompt Used — Model

“You are helping design for college students in a mid-size Indian city who miss class because bus apps show wrong times. HMW: help them know true arrival time before leaving home. Give 10 practical, low-to-medium cost ideas. Avoid only ‘build a full GPS network’.”

🎯 Evaluation of Top AI Ideas — Model

1SMS ETA via USSD shortcode — Desirable ✅ Feasible ✅ Viable ✅
2Crowdsourced “bus spotted” button — Desirable ✅ Feasible ✅ Viable ✅
3Full city-wide hardware GPS retrofit — Desirable ✅ Feasible ❌ Viable ❌
4College-run route WhatsApp bot — Desirable ✅ Feasible ✅ Viable ✅
5Drone surveillance of routes — Desirable ❌ Feasible ❌ Viable ❌

🧠 Reflection

1. Impressive but impractical: Drone surveillance and full GPS retrofit sound advanced but fail feasibility/cost.

2. Human judgment: AI does not know local operator politics, student phone types, or data costs — we must filter.

🧪 Activity 3.6Unit III

Prepare an Idea-Selection Matrix

⏱ 45 min👥 Individual / Group

👨‍🏫 What the Student Should Do

  1. Shortlist 4 ideas (A–D) from earlier activities.
  2. Define 4 weighted criteria (weights sum to 100%).
  3. Score each idea 1–5 per criterion; compute weighted totals.
  4. Identify the winner and test if changing a weight flips the result.

📊 Idea-Selection Matrix — Model Answer

A Live GPS app · B SMS / USSD ETA · C Crowdsourced “spotted” · D QR stop → live map

Criterion User impact (30%) — A:5 · B:4 · C:4 · D:4
Criterion Feasibility (25%) — A:3 · B:5 · C:4 · D:4
Criterion Cost / sustainability (25%) — A:2 · B:5 · C:5 · D:3
Criterion Fits student context (20%) — A:4 · B:5 · C:4 · D:4
Σ Total A: 5×.3+3×.25+2×.25+4×.2 = 3.55 · B: 4×.3+5×.25+5×.25+5×.2 = 4.70 · C: 4×.3+4×.25+5×.25+4×.2 = 4.25 · D: 4×.3+4×.25+3×.25+4×.2 = 3.75
🏆 Winner: B — SMS / USSD ETA (highest total, strong feasibility + low cost)

🧠 Reflection

1. Surprise: Live GPS app felt “best” but scored lower on cost and feasibility.

2. Weight change: If User impact were 50%, A would rise, but B would likely still lead on practicality.

🧪 Activity 3.7Unit III

Select the Top 2–3 Concepts

⏱ 40 min👥 Group

👨‍🏫 What the Student Should Do

  1. Use matrix results and group discussion.
  2. Pick 2–3 concepts worth prototyping — not more.
  3. Write a short name + one-line pitch for each.
  4. Decide which to prototype first and why.

🏆 Selected Concepts — Model Answer

1. BusPing (SMS / USSD ETA)

Pitch: Dial a short code or save one number — get the real arrival time for your route in under 10 seconds, no smartphone data needed.

2. SpotBus (Crowdsourced check-in)

Pitch: Students tap “I see Bus 12” and the map updates for everyone on that route — trust grows with more check-ins.

3. LeaveNow (Smart leave alarm)

Pitch: App learns your stop and class time, then tells you the latest safe minute to leave based on live delay.

🧠 Reflection

1. What made the top stand out: BusPing scores high on feasibility, cost, and reach (works on basic phones).

2. Prototype first: BusPing — can be tested with a simple manual SMS backend before any full system build.
